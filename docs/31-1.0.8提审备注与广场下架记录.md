```
规则版：用户粘贴招聘文字，在手机上根据规则库提示风险，不对企业下结论；内容不上传。
```

## 背景（给团队看，不提交）

1.0.7 代码审核被驳回（微信客服 10387），原因是求助广场属于社交功能（用户内容别人能看到），
个人主体不开放该类目。点名页面：`pages/post-create/index`、`pages/post/index`、`pages/square/index`。

按《广场下架令 2026-11-10》做了完整移除，不再是「只去掉入口」：

- **编译前**生成不含广场三页的 `pages.json`（`scripts/prepare-review-pages.mjs`），构建完恢复；
- 社区接口整体挪到 `services/community.js`，`api.js` 不再导出，也不再出现 `/community/` 字样；
- `postbuild-check.mjs` 改为**硬检查**（原来只打印提示不报错）：三页不在 app.json、目录不在产物、
  7 个禁用词为 0，任一不满足直接构建失败。
